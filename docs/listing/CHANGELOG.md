## Free 0.9.0 (release candidate, unreleased)
- First browser edition. Single PNG, three checks (orphan pixels, doubled corners, partial transparency), coloured overlay, zoom and pan, per-rule toggles, explanations.
- Exact PNG decoding in the browser for every PNG colour type, bit depth and interlacing.
- Privacy: fully offline, and a Content-Security-Policy blocks all network requests.
